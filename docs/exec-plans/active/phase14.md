# Active execution plan: Phase 14 post-gate pivot

## Objective

Convert the generic contraction obstruction into an independently checkable
theorem artifact, then decide whether a restricted exterior coefficient
algebra retains both joint-polynomial contraction and scientific novelty; in
parallel, establish the smallest ordered-sector functional-TN comparator.

## Checkpoints

- [ ] Write an exact-arithmetic independent verifier for the shift-tagged
  Cayley-determinant identity and archive deterministic certificates.
- [ ] Formalize the reduction and direct-sum norm argument as a paper-ready
  theorem with field and complexity assumptions stated explicitly.
- [ ] Classify simultaneously diagonalizable, bounded-nilpotent, triangular,
  and Gaussian/matchgate coefficient algebras by contraction cost and relation
  to LC-AGP/border rank.
- [ ] Reject any subclass whose polynomial exponent grows with chi or whose
  state family is only a fixed-border-rank LC-AGP reparameterization.
- [ ] Implement a minimal ordered-sector functional-basis truth comparator
  using existing 2201/latticeTN infrastructure, without redefining it as
  FEMPS.
- [ ] Compare exact antisymmetry reconstruction, operator interfaces, AD, and
  joint scaling on the smallest N=4 controlled problem.
- [ ] Issue the post-gate route decision: restricted exterior method,
  ordered-sector primary solver, or theory-only/no-go continuation.

## Exit criterion

The hardness reduction has an exact independent verifier and theorem draft,
and one post-gate route has a precise state definition, contraction complexity,
novelty boundary, and small-system truth comparison. No production benchmark
expansion occurs before this decision.
