# Active execution plan: Phase 20 restricted exterior correlation gate

## Objective

Return from the now resource-closed ordered-distance control branch to the
central exterior-algebra problem. Determine whether a restricted matrix-wedge
or statistics-carrier/correlation structure can go strictly beyond known
finite LC-AGP while retaining an exact polynomial contraction, or record a
clear negative result for the selected candidate family.

## Checkpoints

- [ ] Re-audit ADR 0003, the tagged permanent reduction, the finite-AGP prior-
  art boundary, and the small-system exterior oracles before selecting a new
  candidate family.
- [ ] State predeclared admissibility criteria: strict representational content
  beyond LC-AGP/Gaussian structure, exact antisymmetry, an explicit contraction
  recurrence, and polynomial cost in all admitted parameters.
- [ ] Classify the smallest structured core-algebra candidates under gauge,
  block, commutation, and low-rank restrictions; reject families that merely
  reparameterize finite Slater or LC-AGP sums.
- [ ] For the leading candidate, derive either a contraction theorem with
  norm/one-/two-body costs or a reduction/counterexample showing why closure
  fails.
- [ ] Implement only bounded exact materialization and independent exterior
  checks until the contraction argument passes its algebraic gate.
- [ ] If admitted, add AD and N=4/N=6 continuous soft-Coulomb comparisons
  against exterior truth, finite LC-AGP, and the ordered-distance control.
- [ ] Issue Gate H: PASS/CONDITIONAL only for a genuinely distinct tractable
  family; otherwise document the negative result and redirect toward theory/
  paper consolidation rather than relabeling an established method.

## Exit criterion

Gate H does not pass from parameter count or favorable small floating-point
experiments alone. It requires an explicit exact contraction recurrence with a
polynomial complexity derivation, small-system full-materialization
equivalence, and a novelty audit showing that the family is not merely finite
LC-AGP/Gaussian structure. A negative classification is an acceptable phase
outcome.
