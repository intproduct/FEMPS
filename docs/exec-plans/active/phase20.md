central exterior-algebra problem. Determine whether a restricted matrix-wedge
or statistics-carrier/correlation structure can go strictly beyond known
finite LC-AGP while retaining an exact polynomial contraction, or record a
clear negative result for the selected candidate family.

## Exit criterion

Gate H does not pass from parameter count or favorable small floating-point
experiments alone. It requires an explicit exact contraction recurrence with a
polynomial complexity derivation, small-system full-materialization
equivalence, and a novelty audit showing that the family is not merely finite
LC-AGP/Gaussian structure. A negative classification is an acceptable phase
outcome.

## Current evidence

The first candidate, `2 x 2` upper-triangular matrix-pair coefficients, is
closed negatively. Although its coefficient matrices are generically
noncommuting, the square-zero radical permits only one off-diagonal insertion.
Exact rational interpolation gives an LC-AGP expansion with at most
`binom(M+2,2)+2` terms for N=2M and arbitrary boundaries. An independent
M=1--6 certificate plus complex128 state and restricted-gradient tests pass.
Candidate H1 is therefore tractable but fails the beyond-LC-AGP novelty
criterion. The next classification target is uniformly bounded radical
nilpotency with commutative semisimple quotient.
