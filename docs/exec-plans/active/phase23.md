# Active execution plan: Phase 23 exterior no-go synthesis

## Objective

Consolidate the ordinary particle-TT representation no-go and the Phase
13/20--22 exact-contraction classifications into a manuscript-ready theorem
package. State precisely what has been ruled out, what merely collapses to
established AGP structure, and which research directions remain admissible.

## Checkpoints

- [ ] Build one dependency map for the ordinary-TT rank theorems, generic
  matrix-wedge permanent obstruction, bounded-algebra collapse, growing-memory
  collapse, and sparse-path APG obstruction.
- [ ] Audit every theorem hypothesis, field, normalization, reduction type, and
  complexity qualifier against its exact certificate and primary source.
- [ ] Merge the Phase 13 and Phase 22 reductions into a concise hierarchy that
  distinguishes noncommutative virtual hardness from exterior APG coefficient
  hardness.
- [ ] State an explicit coverage boundary: the results do not constitute a
  universal impossibility theorem for all structured or approximate FEMPS.
- [ ] Classify the surviving routes as controlled approximate exterior
  contraction, a proved statistics-carrier/correlation factorization, or the
  already validated ordered continuous first-quantized control route.
- [ ] Produce a paper outline and theorem appendix with claim-to-evidence and
  claim-to-prior-art tables.
- [ ] Run the complete theorem/certificate and relevant physics regression
  suites, then issue the next project decision without starting an unlicensed
  large numerical branch.

## Exit criterion

Phase 23 completes when the no-go story is logically self-contained,
reproducible from clean exact certificates, and narrow enough to survive prior-
art review. Any new affirmative method direction requires its own contraction
and novelty gate.
