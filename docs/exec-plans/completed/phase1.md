# Completed execution plan: Phase 1 no-go package

## Objective

Close the ordinary particle-TT obstruction as a theorem package and build the
small-`N` explicit antisymmetric engine that serves as its numerical oracle.

## Checkpoints

- [x] Define particle unfoldings and prove the exact TT-rank identity.
- [x] Derive the rank floor imposed by exact antisymmetry.
- [x] Prove the flat Schmidt spectrum for a Slater determinant across a
  particle bipartition, with precise normalization conventions.
- [x] Turn the flat spectrum into a best-rank and approximate-TT lower bound.
- [x] Implement wedge materialization, unfoldings, Schmidt spectra, and an
  antisymmetry residual for small `N`.
- [x] Numerically verify all theorem statements for deterministic random
  Slater states and small general alternating tensors.
- [x] Record the distinction from symmetry-preserving low-rank approximation
  literature.
- [x] Produce `docs/theory/no_go.md` and a LaTeX theorem draft.

## Exit criterion

The written theorem set and two independent numerical constructions agree on
all small cases, including rank, singular-value multiplicity, truncation lower
bounds, and exact antisymmetry.
