Return from the resource-closed ordered-distance control branch to the central
exterior-algebra problem. Determine whether a restricted matrix-wedge
coefficient algebra can go strictly beyond finite LC-AGP while retaining exact
polynomial contraction, or record a negative result for the selected family.

## Gate H result

Gate H is **FAIL for the uniformly bounded coefficient-algebra candidate
class**. Exact contraction exists, but only through a polynomial-size LC-AGP
expansion already covered by established state families. Neither
noncommutativity nor bounded radical memory supplies distinct FEMPS correlation
structure.

Within finite-dimensional exact coefficient algebras, avoiding this collapse
requires a semisimple block size or radical nilpotency depth that grows with the
problem. This is only a necessary escape condition; Phase 13 already shows that
unrestricted growing memory can encode a hard row-ordered determinant.
