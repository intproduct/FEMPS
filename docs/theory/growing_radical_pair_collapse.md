# One-generator growing radical still collapses to LC-AGP

## Status

The coefficient-extraction identity below is a proved characteristic-zero
theorem draft with an implementation-independent exact-rational certificate.
It closes the first Phase 21 growing-memory candidate negatively: allowing the
radical nilpotency index to grow is not sufficient to escape polynomial-size
LC-AGP when the radical is generated by one commuting element. The project-
specific classification awaits external review; polynomial interpolation,
Waring decomposition, and Veronese osculation are established mathematics.

## Candidate algebra

Let

```text
A_d = C[z]/(z^d),
Omega(z) = F_0 + F_1 z + ... + F_(d-1) z^(d-1),
```

where every `F_j` is a scalar physical two-form. The radical `(z)` has
nilpotency index `d`, which may grow jointly with particle number and virtual
dimension. An arbitrary boundary functional is specified by

```text
lambda(z^s) = c_s,    0 <= s < d.
```

For N=2M the normalized matrix-pair state is
`lambda(Omega(z)^M mod z^d)/M!`.

## Exact coefficient-extraction theorem

**Theorem draft.** For every `M,d>=1` and every boundary `lambda`, the above
state is an exact LC-AGP with at most

```text
K <= M(d-1)+1
```

terms. The bound is polynomial jointly in `M,d,D`.

**Proof.** Set `L=M(d-1)+1` and choose `L` distinct scalars
`t_0,...,t_(L-1)`. Because `Omega(z)^M` has z-degree at most `L-1`, the
transpose Vandermonde system has unique weights `w_i` satisfying

```text
sum_i w_i t_i^n = c_n,   0 <= n < d,
sum_i w_i t_i^n = 0,     d <= n < L.
```

Writing `Omega(z)^M=sum_(n=0)^(L-1) P_n z^n` gives

```text
sum_i w_i Omega(t_i)^M
  = sum_n P_n sum_i w_i t_i^n
  = sum_(n=0)^(d-1) c_n P_n
  = lambda(Omega(z)^M mod z^d).
```

Every `Omega(t_i)^M/M!` is one scalar fixed-number AGP. Integer nodes
`t_i=i` give exact rational weights whenever the boundary is rational. QED.

This proof is an exact identity, not a small-deformation approximation. It
also supplies a direct arithmetic construction; no root-of-unity cancellation
or limiting parameter is required.

## Exact rank versus border rank

Coefficient extraction is a jet of the Veronese power map:

```text
[z^s] Omega(z)^M = (1/s!) (d/dz)^s Omega(z)^M at z=0.
```

It therefore has a length-at-most-`d` curvilinear/osculating description and a
small border/cactus-rank interpretation. That does not imply an equally small
exact LC-AGP. Already at `s=1`,

```text
[z] Omega(z)^M = M F_0^(M-1) F_1.
```

For `M>=2`, the complex Waring rank of the monomial
`F_0^(M-1) F_1` is `M`, whereas it is a tangent limit of two powers. The exact
rank therefore grows while the border rank stays two. Carlini--Catalisano--
Geramita give the general monomial Waring-rank formula
[@CarliniCatalisanoGeramita2012MonomialWaring]; Veronese osculating spaces and
curvilinear ranks are established geometric frameworks
[@BernardiCatalisanoGimiglianoIda2004OsculatingVeronese;
@BallicoBernardi2012CurvilinearRank].

This distinction is operationally important for FEMPS. A finite-difference
border decomposition can have diverging coefficients and does not by itself
provide an exact, stable contraction. The Vandermonde construction supplies an
exact polynomial term bound, although it likewise does not promise favorable
floating-point conditioning at the naive integer nodes.

## Classification consequence

Candidate I1 is tractable but not beyond LC-AGP. Its growing radical represents
a one-dimensional jet of a scalar AGP family, and exact interpolation expands
that jet using only `O(Md)` established AGP states. This also overlaps directly
with prior nonorthogonal AGP and recent border-rank-motivated AGP-CI
reorganizations [@DuttaChenHendersonScuseria2021NonorthogonalAGP;
@KawasakiGaoScuseria2026AGPCI].

Phase 20 showed that growing simple-block size or growing radical depth is
necessary to escape the uniformly bounded collapse. Phase 21 now shows that
growth alone is insufficient. The next admissible exact candidate must contain
genuinely multibranch noncommutative memory while controlling contraction width;
a single commuting path coordinate cannot supply the desired correlation
multiplicity.
