# Ordered-distance MPS/MPO formulation

## Status and scope

This note describes the finite-grid ordered-distance solver admitted by Gate C.
All identities below are exact on the stated finite grid.  Polynomial
contraction is established for the represented MPS/MPO, but convergence of the
required local cutoff and correlation bond with particle number is not yet a
theorem.  The small dense matrices used in tests are truth oracles and are not
part of the production energy or optimization path.

The method is an ordered-sector, first-quantized tensor network.  It is not the
matrix-wedge FEMPS ansatz and is not given a priority claim; Li--Waintal already
introduced the ordered interparticle-distance MPS direction.  The project-specific
question is whether this representation can carry the functional operator and
automatic-differentiation workflow inherited from Hong et al. (2022).

## Exact finite-grid map

Let `N` particles occupy distinct sites

```text
0 <= p_0 < p_1 < ... < p_(N-1) <= L-1
```

on a centered grid of spacing `a`.  Define `N+1` nonnegative empty-site gaps

```text
g_0 = p_0,
g_i = p_i - p_(i-1) - 1       (1 <= i <= N-1),
g_N = L - 1 - p_(N-1).
```

They obey the exact finite-box charge constraint

```text
sum_(i=0)^N g_i = G,          G = L-N.
```

Conversely, every nonnegative composition of `G` into `N+1` parts gives one
strictly ordered configuration.  Hence the map is a bijection and

```text
# {g : sum g_i=G} = binom(G+N,N) = binom(L,N).
```

The stored ordered-sector vector has unit norm.  If `Psi` is instead a
unit-normalized antisymmetric wavefunction on the full labeled-coordinate
domain, the convention is

```text
psi_ordered = sqrt(N!) Psi restricted to p_0 < ... < p_(N-1).
```

The `N!` permutation chambers have equal norm and collision boundaries have
zero fermionic amplitude, so this rescaling is unitary and leaves Rayleigh
quotients unchanged.

A local cutoff `0 <= g_i <= Q` is an independent projected-basis control.  It
does not alter the charge equation, and `Q=G` recovers the complete ordered
grid sector.

For zero-based particle index `k`, the physical coordinate is

```text
x_k = a [ k - (L-1)/2 + sum_(r=0)^k g_r ].
```

This identity is the source of all operator MPOs below.

## Kinetic and trap operators

Moving particle `k` one site to the left or right transfers one unit between
the adjacent gaps `g_k` and `g_(k+1)`.  The second-order finite-difference
kinetic operator is therefore

```text
T|g> = N/a^2 |g>
       - 1/(2a^2) sum_k (
           |...,g_k+1,g_(k+1)-1,...>
         + |...,g_k-1,g_(k+1)+1,...> ).
```

Terms with a negative gap, a hard-wall violation, or a local-cutoff violation
are omitted.  This is exactly the ordered-coordinate hard-wall kinetic matrix,
not an approximation to it beyond the underlying spatial finite difference.
In the continuous variables the same structure is the mixed-derivative metric
generated by `d/dx_k = d/dg_k - d/dg_(k+1)`.

Because each `x_k` is affine in cumulative gap numbers, the harmonic trap
`sum_k x_k^2/2` expands into a constant, one-site number and number-squared
operators, and two-site products `n_r n_s`.  Kinetic plus trap therefore has

```text
1 + 2N + N + N(N-1)/2
```

explicit product-operator channels in the current direct-sum construction.

## Finite-box projector and soft Coulomb MPO

The exact finite-box projector is a deterministic counter automaton.  Its
virtual state is the cumulative charge `0,...,G`; its last tensor accepts only
charge `G`.  Its MPO bond is `G+1`.

For particles `i<j`, the grid separation is

```text
p_j-p_i = j-i + sum_(r=i+1)^j g_r.
```

Consequently one softened Coulomb term is a diagonal function of a contiguous
interval sum,

```text
V_ij(g) = 1 / sqrt(
    a^2 [j-i + sum_(r=i+1)^j g_r]^2 + epsilon^2
).
```

An interval counter of size `G+1` accumulates the gaps and emits this value at
the right endpoint.  It is exact on `sum g_i=G`, where an interval count cannot
exceed `G`.  The all-pair operator is currently the block direct sum of these
pair MPOs.  Optional Hilbert--Schmidt SVD compression is explicitly
approximate: the locally discarded singular norm is only a diagnostic, so a
small-system restricted operator error is measured independently.

## Hard-charge variational MPS

Penalty enforcement is unnecessary.  At bond `s`, label each MPS virtual state
by a cumulative gap charge `c`.  A local tensor entry is permitted only when

```text
c_right = c_left + g_s,
```

with boundary labels `c_left=0` and `c_right=G`.  Repeated copies of a charge
label supply correlation multiplicity.  If `mu` is the requested multiplicity
per charge, the implementation retains

```text
min(mu, number of reachable left compositions,
        number of completing right compositions)
```

copies.  Thus no unreachable block is allocated and every represented
amplitude has exact total charge `G`.  Forbidden parameters and gradients are
masked after every optimizer step.  The native latticeTN Rayleigh quotient is
optimized by PyTorch AD without gathering a local-dimension-to-the-number-of-sites
tensor.

## Explicit complexity bound

Let

```text
S   = N+1                 number of gap sites,
d   = Q+1                 local dimension,
chi <= mu (G+1)           conservative hard-charge MPS bond,
W_P = G+1                 projector bond.
```

The uncompressed Hamiltonian MPO obeys the conservative bound

```text
W_H <= 1 + 3N + N(N-1)/2 + binom(N,2)(G+1)
     = O(N^2 G).
```

Dense-core storage is `O(S d chi^2)` for the MPS and `O(S d^2 W_H^2)` for the
current MPO representation; its direct-sum block sparsity can reduce the
constant but is not used in the claim.  A standard ordering of the latticeTN
left-environment update gives the upper bound

```text
O[S (W_H d chi^3 + W_H^2 d^2 chi^2)]
```

for one expectation value.  Reverse-mode AD changes constants, not the
polynomial character.  This establishes polynomial contraction in the
representation controls `N,G,Q,mu`; it does not establish that fixed physical
accuracy needs only polynomial `Q` and `mu` as `N` grows.

## Exact checks and remaining continuum gap

The implementation is checked against independently assembled ordered-sector
Hamiltonians for kinetic, trap, finite-box charge, and soft Coulomb terms.
For the controlled `N=4,L=8,a=0.7` problem, native MPS/MPO energy agrees with
the 70-dimensional truth matrix to `5.33e-15`; CPU/Blackwell energy and AD
gradients agree to `5.33e-15`.

This closes the finite-grid contraction question only.  The local gap values
are grid occupations, not yet coefficients of an orthonormal continuous
half-line functional basis.  The next gate must introduce Dirichlet half-line
bases (and a full-line center-of-mass basis), derive their mixed-derivative and
interval-interaction matrices, and demonstrate independent basis/box/
correlation convergence.  Until then this is a controlled finite-grid
first-quantized solver, not a completed 2201 continuous-basis fermionic method.
